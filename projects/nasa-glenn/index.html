Xenon recovery cart

  • Produced a complete control schematic for the cart used in electric propulsion testing — start/stop latching circuit, control relay, solenoid valve and pressure-switch interlocks off 120 VAC
  • Standardized every device tag to TS/PB/CR/SOL convention with full terminal mapping, so the sheet can actually be used to wire and troubleshoot the panel
  • Delivered as a build package — title block, revision table and BOM — with extraneous views stripped so it stays focused on power and control

Preventive maintenance program

  • Built a ventilation controls PM plan covering every TC010M and TC010MA turbopump controller in the branch
  • Intervals driven by controller hour-meter runtime — 24-hour airflow checks through 2,000-hour fan replacement and 40k/80k/120k-hour overhaul alarms
  • Replaced ad-hoc record keeping with a unified checklist and log

Gauge cart operations

  • Qualified as a gauge cart operator and executed calibration test runs independently
  • Documented results and status for each unit, clearing the branch's outstanding backlog
  • Hands-on with roughing pumps, high-vacuum pumps, gauge types and the PLCs tying them together

What the summer actually taught me

  • Tools are application layers — the engineer solves the problem; AutoCAD and the PLC are where the answer gets written down
  • Technical strength with weak communication is capped impact
  • Work upward from the simplest solution; a lot of facility problems end there
